# Aravest "Next Phase" v20 — MAC design language

Seven core archetype slides for the evolving v20 narrative, restyled to match the
visual design language of the amended **MAC Paper** (`260715_MAC_Paper_—_Aravest_Next_Phase_v_2`).
Kept as HTML so the narrative can keep changing after the discussion with the boss.

Open `Aravest_Next_Phase_v20_MAC.html` in any browser (arrow keys / on-screen nav).
`Aravest_Next_Phase_v20_MAC.pdf` is the print export; `renders/` holds per-slide PNGs;
`build_slides_mac.py` regenerates the HTML (`python3 build_slides_mac.py`).

## The seven archetypes
1. **Cover** — Marina Bay skyline photo, navy scrim, steel rule.
2. **Chapter divider** — same photo treatment, chapter number + contents.
3. **The Aravest Way** — first-principle left-rule block + three top-accent value cards + banded philosophy table.
4. **AUM build chart** — navy staircase → three direct-labelled track-record outcomes at Year 5.
5. **Deployment table** — navy-header banded table, bold-navy first column, totals rule.
6. **Deal slide (Marina One)** — teal top-accent card + metric tiles (Pathway 2).
7. **Transaction mix** — direct-labelled proportion bars (navy sequential ramp).

## Design language applied (from the attached MAC Paper)
- **All-sans (Aptos)** — no serif face anywhere.
- **Grey kicker + descriptive subline**, bold-navy sans title.
- **Top-accent cards** — thin coloured top bar, letter-spaced caps label, bold-navy heading, graphite body.
- **Banded tables** — navy header / white text, alternating `#F4F5F6` rows, bold-navy first column.
- **Navy left-rule statement blocks** for the key takeaway on each analytical slide.
- **Skyline photography** on cover and dividers.
- **No gold, no serif, no dark full-width conclusion bands** — light and airy.
