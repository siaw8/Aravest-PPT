# Calibration Set v3 — density and readability pass

V3 keeps the v2 direction intact (restrained gold, Spectral only on covers + one editorial
phrase, flat geometry — no cards, no shadows) and addresses the two v2 issues: body type too
small, and slides feeling too sparse. Target: a premium institutional Board deck — calm,
readable, substantive, authoritative.

## Type scale (Board / IC working slides)
| Element | v2 | v3 |
|---|---|---|
| Body / matrix values | 11–11.5pt | **13pt** |
| Table text (pipeline) | 11pt | **12pt** |
| Governing principle / decision body | 11.5pt | **13.5pt** |
| Executive-summary conclusions | 10.5pt | **12–12.5pt** |
| KPI figure (US$300m) | 30pt | **34pt** |
| Section labels / eyebrows | 8.5–9pt | **9–9.5pt** |
| Footnotes / source | 8.5pt | 8.5pt (unchanged — deliberately quiet) |

## Density changes on the three flagged slides
- **Slide 3 (Executive summary):** each of the four conclusions now carries a lead line **and** a
  supporting line (drawn from the narrative — the "responsibility before a business" principle,
  the confidence-progression, etc.), so the columns fill the middle band. Closing synthesis
  promoted to a navy-ruled "One strategy." statement. Empty vertical space removed.
- **Slide 4 (Two pathways):** values enlarged to 13pt; header block pulled up; five comparison
  rows tightened into a fuller, continuous matrix; the parallel-relationship conclusion sits on a
  navy rule with clear separation from the footer.
- **Slide 5 (Capital & AUM):** larger US$300m figure and anchor text; taller schematic bars;
  captions raised to 11.5pt; Conrad proof line to 12.5pt. The mid-slide gap is closed.

## Unchanged from v2 (guardrails held)
- **Gold:** still only 3 elements across 7 slides (two cover rules + the single decision marker).
  Working slides carry no gold.
- **Spectral:** covers + the one *institution-building* phrase only (~3% of text). Everything else
  Aptos Display / Aptos.
- **No cards, shadows, accent strips or facet decoration** on working slides; hairline rules and
  typography-led hierarchy throughout. Three rhythms (editorial / analysis / governance) preserved.
- Content remains verbatim / near-verbatim from the Locked Board Strategy Narrative v8; no figures
  invented (US$300m is the only stated number; AUM profiles are labelled illustrative).
